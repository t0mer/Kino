# Demo background music

The music bed in `assets/demo/demo.mp4` is generated by `demo/music.py`. It is synthesised
from scratch with numpy: no samples, no downloads, no vocals, no third-party material.

| Parameter | Value |
|---|---|
| Tempo | 100 BPM |
| Key / progression | D major, I-V-vi-IV (D, A, Bm, G), one chord per bar |
| Loop | 8 bars (19.2 s), note tails wrapped to the start so it tiles seamlessly |
| Voices | plucked eighth-note arpeggio (two patterns), detuned sine pad, soft bass pulse on every beat (no percussion) |
| Tone | one-pole low-pass at 3.5 kHz |
| Seed | `1009` (only for slight arpeggio velocity variation) |
| Sample rate | 48 kHz mono |
| Level | -32 dBFS RMS before mixing (the speech clips sit around -22 dBFS) |

`demo/build.py` loops/trims the bed to the video length, ducks it under the narrator
(`sidechaincompress=threshold=0.05:ratio=8:attack=20:release=400`), mixes it with the voice,
normalises with `loudnorm=I=-23:TP=-1.5:LRA=11`, and fades it out with the picture.

Regenerate on its own:

```bash
demo/.venv/bin/python demo/music.py --seconds 150 --out music.wav
```
